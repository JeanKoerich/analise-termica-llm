# Roteiro sugerido para vídeo de 90 a 120 segundos

**0–15 s — Problema:** mostrar o contexto do monitoramento térmico e a dificuldade de interpretar os indicadores.

**15–35 s — Arquitetura:** explicar rapidamente fonte de dados → validação → indicadores → LLM → Streamlit.

**35–75 s — Execução real:** abrir o dashboard, selecionar um período, mostrar os indicadores e executar a análise com LLM (somente após validar essa integração).

**75–100 s — Verificação:** comparar uma ou duas afirmações do relatório com os números exibidos e mostrar uma situação de dados insuficientes.

**100–120 s — Resultado e limites:** mostrar a utilidade do relatório e explicar que o LLM interpreta dados, não substitui os cálculos nem a decisão humana.
